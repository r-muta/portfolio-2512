## 2. 見出し階層

確認方法: 画面に表示されている h1〜h4 を Playwright で抽出しました。

| ページ | 修正前 | 修正後 |
|---|---|---|
| トップ（PC） | h1: 作品名 | 変更なし |
| トップ（SP） | **h1 なし**（PC 用の h1 は `display:none`）、h2: 作品名 | h1: 作品名 |
| About | h1 → h2「ムタログ」だけ（Profile / Career / Identity は `<span>`） | h1 → h2 Profile → h2 Career → h2 ムタログ → h2 Identity（→ モーダルの h3） |

| Contact / Thank you / 404 | h1 のみ | 変更なし |

Tailwind v4 の Preflight は h1〜h6 の `font-size` と `font-weight` を `inherit` に、`margin` を 0 にリセットします。そのため、クラスが同じならタグを変えても見た目は変わりません（スクリーンショットでも確認済み）。

**提案（未対応）:**
- トップには PC 用と SP 用の `<main>` が 2 つあります（片方は `display:none` なので支援技術には 1 つしか見えません）。将来まとめる機会があれば 1 つにするのが望ましいです。

## 4. meta / OGP

### 4-1. 修正前の状態

- 全ページが `"use client"` なので `metadata` を export できず、**全ページの title が「Ryuta Mukai | Web Designer」**、description も英語の 1 文で共通
- `og:image` は `opengraph-image.png` から自動で出ているが、`og:title` / `og:description` / `og:site_name` / `og:locale` / `og:type` / `twitter:card` がない
- `metadataBase` がなく、OGP 画像の絶対 URL は Vercel の環境変数頼み
- `robots: noindex, nofollow` と `X-Robots-Tag` は意図どおり（SNS のリンクプレビューは noindex の影響を受けません）

### 4-2. 対応

- `src/lib/metadata.ts` を新設し、OGP・Twitter カードの共通値をまとめました。Next.js は子ページで `openGraph` を指定すると親の値を丸ごと上書きします（実際に、子ページで画像と `site_name` が消えるのを確認しました）。そのため、子ページは共通値を展開してから title / description だけ差し替えます。
- ルートに `metadataBase`、title テンプレート（`%s | Ryuta Mukai`）、`og:type` / `og:locale` / `og:site_name` / `og:image:alt`、`twitter:card=summary_large_image` を追加
- ページ側は client component のままにして、`layout.tsx`（server component）を足し、そこで meta を指定:
  - `/about` → `Profile | Ryuta Mukai`
  - `/contact` → `Contact | Ryuta Mukai`
  - `/contact/thank-you` → `Thank You | Ryuta Mukai`
  - `/works/[slug]` → `{作品名} | Ryuta Mukai`。description には作品の overview を使用
  - 404 → `404 Page Not Found | Ryuta Mukai`
- `metadataBase` は `NEXT_PUBLIC_SITE_URL` → `VERCEL_PROJECT_PRODUCTION_URL` → `https://portfolio-2512.vercel.app`（`DEPLOYMENT_SUCCESS.md` の URL）の順で決まります。**独自ドメインがある場合は、Vercel に `NEXT_PUBLIC_SITE_URL` を設定してください。**

ビルド後の HTML で、全ページに `og:image`（1200×630）・`twitter:card`・ページ別の `og:title` が出ていることを確認済みです。

### 4-3. 提案

- トップの description が英語 1 文だけなので、日本語の紹介文（例:「横浜を拠点に活動する Web デザイナー 向井龍太のポートフォリオ。Shopify・Studio での EC・ブランドサイト制作実績。」）にすると共有時の見え方が良くなります。文面はむたさんの判断なので変えていません。
- `src/app/icon.png` が 120×120 なので、iOS のホーム画面用に 180×180 の `apple-icon.png` を追加するのがおすすめです。
- 作品ごとの OGP 画像（サムネイルの 1200×630 版）を `works/[slug]/opengraph-image.png` などで用意すると、作品ページを共有したときにその作品の画像が出ます。

## 5. 画像の容量とサイズ

### 5-1. 対応: 可逆圧縮（画素は同一）

oxipng（レベル 4）で全 PNG を最適化しました。各ファイルについて、圧縮前後のデコード結果が RGBA で完全に一致することをスクリプトで検証しています。消したのはメタデータの `gAMA` チャンクだけです（`sRGB` チャンクがあるので表示には使われません）。

| 対象 | 修正前 | 修正後 | 削減 |
|---|---|---|---|
| `public/images` 46 ファイル + `opengraph-image.png` + `icon.png` | 35.86MB | 29.72MB | −6.1MB（−17%） |
| トップ（サムネイル 6 枚） | 約 5.1MB | 約 4.1MB | −19% |
| About（プロフィール写真 + ムタログ画像） | 4.8MB | 3.9MB | −19% |
| OGP 画像 | 445KB | 377KB | −15% |

あわせて、スクロールしないと見えない画像（詳細ページのブロック画像・ギャラリー、About のムタログ画像）に `loading="lazy"` と `decoding="async"` を付けました。トップのカルーセル画像は、切り替え時に画像が遅れて出るのを避けるため付けていません。

### 5-2. 問題点と提案（見た目に影響しうるため未対応）

1. **`<img>` で元の PNG をそのまま配信している**（トップ・About・詳細ページ）。Identity モーダルだけが `next/image` です。
   - 例: About のプロフィール写真は 2400×1200・2.0MB ですが、表示幅は最大 720px（Retina でも 1440px）です。
   - `next/image`（`sizes` 付き）に置き換えると AVIF / WebP に変換され、サイズも表示幅に合わせて配信されます。**転送量は 1/5〜1/10 程度になる見込み**です。
   - ただし `next/image` を使うとラッパー要素や表示の挙動が変わります。トップは `imgRef.clientHeight` で位置を計算しているので、置き換えたら目視確認が必要です。
2. **写真なのに PNG**: プロフィール写真、Identity の 17 枚（各 500KB〜1.3MB、800×800）は写真なので、WebP / AVIF（品質 80 前後）にすると 1 枚 50〜150KB 程度になります。
3. **`width` / `height` 属性がない**: どの `<img>` にも付いていないので、読み込み時にレイアウトがずれます（CLS）。`aspect-[16/10]` が付いていない詳細ページのブロック画像（1600×900）と About の画像が対象です。
4. **使われていない画像**: `public/images/identity/Minimalism.png`（1.27MB）はどこからも参照されていません（`likes.ts` は `Minimalism_02.png` を参照）。削除してよいかはむたさんの判断なので残しています。
5. 不要ファイル: リポジトリ直下に空ファイル `next` と `portfolio_2512@0.1.0` があります（コマンド入力のミスで作られたもののようです）。`src/components/BottomNav.tsx` と `EmojiSwitcher.tsx` はどこからも import されていません。

## 7. その他、気づいた点（提案）

- **トップのホイール・矢印キー操作が `window` 全体に効いている**: 768px より広い画面では、ページ内のどこにフォーカスがあっても ↑↓←→ で作品が切り替わり、`preventDefault` でスクロールも止まります。Tab でリンクを移動する分には問題ありませんが、フォームなどを足す場合は注意が必要です。
- **Identity モーダル**: Esc で閉じられない、開いてもフォーカスがモーダルに移らない、閉じたあとフォーカスが元のボタンに戻らない。ロジックの変更になるので今回は見送りました。
- **`prefers-reduced-motion` に未対応**: カルーセルとモーダルのアニメーションに、動きを減らす設定の配慮がありません。
